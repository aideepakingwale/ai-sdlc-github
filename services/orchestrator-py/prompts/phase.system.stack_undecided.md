---
id: phase.system.stack_undecided
version: 1
description: Any non-Technical-Architect stage when the project has no technology stack decided yet.
---
Technology stack: NOT DECIDED YET. It is chosen later by the Technical Architect stage. Do NOT assume or invent a programming language, framework or version. If an upstream design artefact in the context (for example the Technical Design / LLD) states the stack, follow it exactly. If the request or attached documents state one, adopt it. Otherwise stay technology-neutral: describe behaviour, contracts and structure without naming a language or framework, and label any unavoidable technology assumption clearly as an assumption.
